# public/lottie

Asset finali pronti per Remotion e HyperFrames. **Questa cartella viene generata** da `convert.py`
(vedi README principale) e si può committare, così basta scaricare questa cartella dal repo.

- `animated_emoji/` e `animations/`: un file Lottie JSON per emoji (nome = codepoint Unicode, es. `1f600.json`)
- `manifest.json`: elenco con `id`, `file`, `emoji`, `set`, `fps`, `durationInFrames`, `durationInSeconds`, `width`, `height`
